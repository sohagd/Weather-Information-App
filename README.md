# Weather Information App

A Python-based Weather Information Application that fetches real-time weather information using the OpenWeather REST API.

This project was developed as part of my Python Development Internship at Auspify Technologies.

## Project Overview

The Weather Information App allows users to search for a city and retrieve its current weather information.

The application integrates a REST API to fetch real-time weather data and processes the returned JSON response to display useful weather information.

## Features

- 🔍 Search weather by city name
- 🌡️ Display current temperature
- ☁️ Display weather conditions
- 💧 Display humidity
- 💨 Display wind speed
- 🌬️ Display atmospheric pressure
- 🌍 Real-time weather information
- ⚠️ API error handling
- ⚠️ Invalid city handling
- 🖥️ User-friendly interface

## How It Works

1. The user enters a city name.
2. The application sends a request to the OpenWeather API.
3. The API returns weather information in JSON format.
4. The application extracts the required weather data.
5. The information is displayed to the user.
6. Errors are handled appropriately when the request fails.
